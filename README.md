# Design QA Auditor

Скилл для Claude Code и других агентов: аудит Figma-макетов, HTML-сайтов и приложений перед передачей в разработку или релизом.

Агент работает как независимый дизайн-тестировщик и проверяет:

- **систему**: токены и Variables, компоненты, инстансы, Auto Layout, Hug, Fill и Fixed;
- **вёрстку**: адаптив на контрольных ширинах, переполнение, обрезанный текст, стресс-тест контента;
- **поведение**: состояния, формы, мёртвые клики, доступность по WCAG 2.2 AA;
- **анимации**: у каждого интерактивного элемента анимирована смена состояния (hover, нажатие, фокус, открытие и закрытие), длительность, кривая, `prefers-reduced-motion`;
- **системные контролы**: никаких голых `<select>`, системных пикеров, чекбоксов, `title`-подсказок и `alert()`, которые рисует ОС мимо дизайна;
- **мобильную версию**: набор устройств от 320 до 430 px и горизонталь, пропорции и раскладку, читаемость, контент только по наведению, фиксированные панели, `100vh`, safe area, клавиатуру, тап-зоны, паритет с десктопом и обязательный проход ключевых сценариев на телефоне;
- **тексты**: символы вместо иконок, кавычки, тире, неразрывные пробелы, единые термины и цены;
- **продукт**: проходит пользовательские сценарии целиком и ищет тупики, разрывы и лишние шаги;
- **сверку Figma и HTML**: пары экранов, тексты, токены, первопричину расхождений;
- **end-to-end прогоны**: каждый ключевой сценарий записывается в повторяемый прогон (Playwright для веба, Maestro для мобильных приложений и мобильного веба) с негативными ветками, перезапуском, двойным нажатием, кнопкой «назад», горизонталью и проверкой на стабильность. Прогоны лежат в `qa-e2e/` и перезапускаются при повторном аудите, чтобы ловить регрессии;
- **мобильные приложения** (режим APP QA): iOS, Android, React Native и Flutter на симуляторе или устройстве через Maestro.

Результат пишется в `DESIGN_QA_REPORT.md`: баг-репорты с приоритетами P0–P3, доказательства в `qa-evidence/` и решение QA (PASS, PASS WITH ISSUES, FAIL или INCOMPLETE). Повторный аудит сверяется с прошлым отчётом и отмечает исправленное, оставшееся и регрессии.

## Скрипты

В `skills/design-qa-auditor/scripts/` два скрипта, только на чтение:

- `figma-audit.js` для Figma MCP (`use_figma`): цвета, отступы и радиусы без переменных, текст без стиля, Fixed Height с текстом, отвязанные инстансы, скрытые слои, маленькие кнопки, наличие мобильных фреймов, мелкий текст и текст у края на мобильных экранах, интерактивные компоненты без вариантов hover, pressed, focus, disabled и без анимированных переходов, типографика;
- `web-audit.js` для браузера (`javascript_tool`): переполнение, обрезанный текст, тап-зоны, на мобильной ширине meta viewport, iOS-зум на полях, мелкий текст, высоту фиксированных панелей, тесные тап-зоны, искажённые картинки, контент только по hover, `100vh`, список действий для сравнения с десктопом, подписи элементов, контраст, убранный фокус, элементы без перехода состояний, системные контролы, захардкоженные цвета в CSS, заголовки, типографика.

Скрипты дают список кандидатов, а не готовые баги: агент сортирует находки и отбрасывает служебные слои и допустимые решения.

## Установка

Claude Code, как плагин:

```
/plugin marketplace add me0wdes/design-qa-auditor
/plugin install design-qa-auditor@design-qa-auditor
```

Через [skills CLI](https://github.com/vercel-labs/skills), для Claude Code, Codex, Cursor и других:

```bash
npx skills add me0wdes/design-qa-auditor
```

Вручную: скопировать `skills/design-qa-auditor` в `~/.claude/skills/`.

## Запуск

`/design-qa-auditor` или «проверь макет», «аудит Figma», «сверь Figma и HTML», «проверь сайт перед релизом», «прогони сценарии», «проверь мобильное приложение» со ссылкой на Figma, сайт или локальный проект.

Глубина: быстрая, стандартная (по умолчанию) или глубокая. Скилл ничего не исправляет без разрешения, изменения в Figma делает только на копиях фреймов.

Для проверки Figma нужен Figma MCP, для сайтов браузер с инструментами агента. Для E2E-прогонов Playwright и/или [Maestro](https://maestro.dev) с симулятором или эмулятором. Скилл ничего не ставит сам: если инструмента нет, спрашивает или проходит сценарии руками и отмечает прогоны как BLOCKED.
